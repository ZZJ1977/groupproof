# 学生端入口复核与独立项目

用户要求：清理模拟记录不删除业务功能；创建独立项目不要求加入课程。

## 已修复

- `/projects/new` 为独立创建表单，接现有 A `POST /api/v1/a/projects`；创建者为组长，course_id/group_id 均为空。首页与课程列表的创建入口指向此页。
- 课程项目单独通过 `/courses?intent=create-project` 选择课程，保留课程组队/规则校验。加入课程仍为独立的 `/courses/join`。
- 课程卡片恢复原有“查看课程规则”，补充 `/courses/:id/files` 学生别名，沿用真实课程文件授权与下载服务。
- 修复全局链接颜色覆盖按钮颜色、搜索按钮窄宽换行问题。

## 入口核对（与清理前 a51d4c3 比较）

| 范围 | 核对结论 |
| --- | --- |
| 首页、课程、待办、通知、个人动态 | 路由保留，空数据不隐藏创建/加入操作；API 错误可重试 |

| 里程碑、证据、GitHub、飞书、文件、讨论 | 原项目导航保留，接 B/C/D 和项目集成接口 |
| 贡献、报告、导出、设置、归档/重开 | 原路由与现有权限保留；只读或业务条件不足时仍按服务端限制操作 |

导航存在不等于外部服务已配置。文件正文自动提取、全局搜索和外部平台真实授权仍有原有接入边界；未以假数据或假成功填补。全局搜索当前提示使用页面筛选。第三方授权、邮件和文件存储需要实际配置与授权验收，本次不冒充已实测。

- 隔离浏览器验证：首页独立创建与加入课程互不依赖、失败保留表单、成功跳到新项目、13个子页面导航和总览入口保留、390px窄屏。
