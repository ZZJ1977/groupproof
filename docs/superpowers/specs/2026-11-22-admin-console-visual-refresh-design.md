# GroupProof 管理后台视觉改版设计

## 意图

把现有 `/admin/*` 统一成面向平台管理员的轻量数据工作台。参考用户提供的管理看板案例，保留 GroupProof 的蓝色识别、中文信息层级、真实环境切换和现有 API 契约，同时让首页更像运营看板，让用户、教师、课程和日志页面更像高密度操作台，让 AI 使用情况成为可解释的分析中心。

## 目标

- 首页第一屏能回答平台规模、待办、运行状态和近期活动四个问题。
- 用户、教师、课程和日志页面在一个紧凑的筛选工具栏内完成查询，并把主要操作固定在标题行。
- AI 用量页突出 OpenRouter 来源、请求量、成功率、Token、费用和业务场景分布。
- `develop / Staging` 与 `main / Production` 环境切换始终可见，页面数据来源明确。
- 统一加载、空数据、错误、无权限和窄屏状态，不改变现有接口、路由、权限和审计语义。

## 非目标

- 不新建第二套管理员前端或修改现有 `/admin/*` URL。
- 不在本轮更换 API、数据库表、认证方式或 OpenRouter 计费逻辑。
- 不把演示数据伪装成真实服务数据；真实页面继续沿用现有 real/mock 分流。
- 不引入新的图表依赖，趋势图使用现有 React、CSS 和 SVG/CSS 能力。

## 设计方向

采用“浅色数据工作台”方向。管理后台使用浅灰画布、白色表面、深蓝文字、蓝紫渐变作为分析强调色和 14–18px 圆角卡片。侧栏保持稳定宽度并按任务分组，当前项使用高对比的蓝色胶囊状态。顶部保留搜索、环境、语言、通知和账户入口；管理页的全局搜索在真实服务模式下继续提示使用页面筛选。

## 页面模板

### 管理总览

标题行 + 环境说明 → 四个 KPI 卡片 → 近 7 天平台活动趋势 → 待处理队列与最近账号 → 账号/课程分布 → 服务连接状态。

KPI 使用真实查询结果，趋势图在没有足够时间序列时显示“暂无趋势样本”，不生成虚假增长率。

### 用户、教师、课程

标题行放页面说明、刷新和新增/创建操作；下面是一行筛选工具栏；主体是可横向滚动的表格；点击行打开右侧详情面板。空状态只占据表格区域，并提供下一步入口或说明。

### 系统日志

日志来源切换、审计筛选、结果状态标签、可读对象摘要和详情抽屉。原始 ID 默认缩略，敏感字段继续遵守后端脱敏结果。

### AI 使用情况

OpenRouter 来源标签 → 时间和用户筛选 → 请求、费用、Token、成功率、未计价记录 KPI → 请求趋势 → 数据质量 → GitHub 分析、群聊证据追踪、需求解析、任务规划和风险解释的业务场景分布 → 模型与功能明细。

## 视觉变量

- 画布 `#F6F8FC`，表面 `#FFFFFF`，正文 `#0F172A`，辅助文字 `#64748B`。
- 主操作 `#2563EB`，主操作深色 `#1D4ED8`，分析紫 `#7C3AED`，成功 `#059669`，警告 `#D97706`，危险 `#DC2626`。
- 控件圆角 10px，卡片圆角 16px，侧栏选中项圆角 12px。
- 页面间距 24px，卡片间距 16px，卡片内边距 20–24px，表格行高不低于 52px。
- 正文使用系统中文无衬线字体，不加载外部字体。
- 状态必须同时使用文字和颜色，焦点环清晰可见。

## 数据与权限边界

页面继续消费现有 `cIdentityClient` 与 `createGovernanceClient`，环境选择由 `admin-environment` cookie 和现有代理决定。前端只负责展示服务返回的真实数据和后端脱敏结果，不能把本地 mock 记录混入 real 目录，也不能在视觉上把空数据当成零增长结论。

## 验收标准

- 桌面 1440px、平板 1024px、窄屏 768px 和 375px 下，导航、筛选、表格和详情仍可操作。
- 所有管理页面标题行、筛选栏、按钮、状态标签、表格和分页遵循同一套组件样式。
- real 模式下环境切换后，页面重新请求并显示对应环境数据；切换失败保留可重试错误。
- AI 页面保留现有业务场景定义和计费完整性提示。
- `npm run lint`、`npm run typecheck`、`npm run build`、`npm run check:routes` 通过。

## 取舍说明

考虑过单独创建一套全新的管理员应用、只改 CSS、以及在现有页面上做结构化改版。单独应用会重复认证、环境切换和 API 适配，范围过大；只改 CSS 无法解决筛选区层级、详情呈现和首页看板结构。最终采用现有路由和数据层上的结构化改版，先改共享壳层与治理组件，再改首页和 AI 看板，最后补齐日志与窄屏验收。
