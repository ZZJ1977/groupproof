# 阶段 13 交付：后端接口交接表

更新日期：2026-10-06。本表整理 B 功能与共享依赖的操作契约，供 FastAPI 后端接入。当前全部操作运行在 Mock 前端（浏览器 localStorage）；不虚构已部署的 API URL 或第三方调用。身份一律来自服务端会话（UI 不提交 actorId），数据库用事务与条件版本更新（`expectedVersion` 不匹配返回 `VERSION_CONFLICT`），文件用对象存储与受授权读取。

统一约定：

- 资格判断复用 `lib/access/policy.ts` 的 `can(data, actor, action, target)`；服务端需实现同等矩阵（阶段 01 权限表）。
- 版本模型见 `lib/versioning.ts`：修订不可变、草稿可改、确认绑定 `revisionId + contentVersion + memberRoster`。
- 命令执行器语义见 `lib/commands/core.ts`：输入校验 → 资格 → 版本 → 业务状态 → 原子写入（主体+日志同批）→ 成功后返回；错误码 `VALIDATION_ERROR / NOT_FOUND / FORBIDDEN / INVALID_STATE / VERSION_CONFLICT / STORAGE_ERROR`。
- `expectedVersion` 统一取聚合并发版本（项目/课程版本）。
