# 阶段 15：动效规范与本轮接入

更新日期：2026-10-06 · 依据：[阶段 15 规格](15-动态交互与动效规范.md)、[14 UX 规范](14-UX设计规范.md) · 状态：规范完成 + 本轮页面接入完成（其余页面按接入清单推广）

## 1. 运动 Tokens（`app/globals.css`，阶段 14 已落位）

| Token | 值 | 用途 |
|---|---|---|
| `--gp-dur-fast` | 150ms | 按钮/控件状态变化 |
| `--gp-dur` | 180ms | 常规状态变化（默认基线） |
| `--gp-dur-slow` | 200ms | 面板进入/列表结构变化 |
| `--gp-ease` | ease-out | 统一曲线（进入/反馈为主） |
| `--gp-transition` | opacity/transform/background-color/border-color/color 组合 | `.gp-transition` 工具类 |
| `.gp-fade-in` / `.gp-slide-in` | 180–200ms 进入动画 | 反馈条/面板进入 |

## 2. 组件运动规则

| 组件/变化 | 触发 | 起 → 止 | 时长/曲线 | 可中断 | 减少动效 |
|---|---|---|---|---|---|
| 按钮 hover/按下 | 指针/键盘 | 颜色 → 颜色 | 150ms ease-out | 是 | 即时切换 |
| 保存状态（未保存/保存中/已保存/失败） | 真实业务状态 | 文案+颜色切换 | 150ms | 是（状态驱动） | 保留文字反馈，无位移 |
| 操作反馈条出现 | 命令结果 | opacity 0→1（+6px 上移） | 180–200ms | 是 | 即时显示 |
| Dialog/抽屉 | 打开/关闭 | 遮罩淡入 + 面板位移/淡入 | 200ms ease-out | 是（关闭立即可再开） | 无位移淡入或即时 |
| Tab/视图切换 | 点击 | 内容区淡入 | 150ms | 是 | 即时 |
| 列表项新增/更新 | 数据变更 | 新项淡入；更新项高亮→常色 | 180ms | 是 | 即时 |
| 统计/进度条 | 数据变更 | 宽度/数值过渡 | 180ms | 是 | 直接跳变 |
| 键盘焦点移动 | Tab | 焦点环即时可见 | 0ms | — | 不变（焦点必须可见） |

**硬性规则**：保存/发布/确认等业务操作由真实命令状态驱动（`useCommands.pending`/结果），**不等待动画结束**、不使用动画计时；错误信息不被动画遮挡；焦点不因动画移出可见范围。

## 3. 本轮接入范围（实际代码）

- `app/globals.css`：Tokens、`.gp-transition/.gp-fade-in/.gp-slide-in`、`prefers-reduced-motion: reduce` 全局降级（动画 1ms、transition 1ms、平滑滚动关闭）。
- `components/ui/button.tsx`：transition-colors + loading 态（aria-busy、文案“处理中…”）。
- `components/common.tsx`：`Feedback` 渐入（gp-fade-in）、`SaveState` 状态切换（data-state 驱动，无位移）。
- 代表页 07/10/47 及推广页（08/09/23/29/35/38–40/46）：按钮过渡、保存状态、反馈条渐入；任务视图切换沿用页内导航（150ms 内容淡入由 `.gp-fade-in` 提供）。
- Dialog/工作区导航：沿用现有实现（遮罩/抽屉已有过渡；hover 即时反馈），未新增依赖（CSS 覆盖需求）。
