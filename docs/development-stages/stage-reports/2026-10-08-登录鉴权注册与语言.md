# 迭代总结：登录鉴权、注册闭环、用户数据库与全站语言

日期：2026-10-08 · 依据：[实施方案 v1.1](../../plans/2026-10-08-auth-registration-language-plan.md)（P0–P5）· 状态：核心完成，遗留项见文末

## 任务范围

1. 用户账户与注册审核数据库（PostgreSQL：资料/Google 身份/邮箱验证/教师审核/会话/审计）；
2. 真实 Google 登录与注册闭环（按数据库当前事实决定去向：受限个人中心 / 已授权业务 / 停用拒绝）；
3. 登录页移除“完善个人资料/验证邮箱”入口，Google 为唯一账号入口；旧 onboarding 链接保留兼容并经相同门禁；
4. 全站语言（简体/繁體/English，next-intl，Cookie > 账户偏好 > Accept-Language > zh-Hans）。

## 完成内容

### P0 契约与配置

- `.env.example`：APP_MODE/APP_ORIGIN/API_INTERNAL_URL/GOOGLE_*/DATABASE_URL/SMTP_*/EMAIL_CHALLENGE_HMAC_KEY/学校规则/会话期限占位；真实值不进代码与提交记录。
- 字段字典与表关系：`server/docs/DB_FIELD_DICTIONARY.md`（申报/事实/派生分层、三层检查落点、未确认学校规则标注）。

### P1 后端（FastAPI + PostgreSQL，`server/`）

- 迁移 `migrations/versions/0001_user_account_and_registration.py`（Alembic）：users、auth_identities、school_email_bindings、academic_identity_checks、sessions、email_challenges、teacher_applications、auth_audit_events、oauth_transactions、auth_rate_limits、email_outbox；唯一约束（规范用户名 / Google 身份键 / 已验证规范邮箱 / 当前挑战部分唯一索引）、外键、事务边界。
- RegistrationFacts 派生（disabled → profile → email → review → active）；三层检查分离（格式 / 一致性唯一性 / 身份真实性）；`academicIdentityStatus` 首期保持 `unverified`，不宣称学校实名已核验。
- Google OIDC（Authlib：Authorization Code + PKCE S256 + state/nonce 事务持久化 + JWKS 验签）；可撤销/轮换会话（onboarding/full/status_only + 闲置/绝对期限）；验证码（HMAC 存储、一次性行锁消费、限流、重发作废、原子绑定）；换绑独立流程（旧邮箱一次性确认/近期重认证前置）；教师申请绑定资料快照、审核批准/驳回、依据变更撤销教师资格；停用即时撤销会话；CSRF + Origin 校验；returnTo 白名单；审计只记字段名。
- 受保护业务接口样板（`routers/business.py`）：会话 + 注册资格 + 资源权限三层独立校验；公开总览仅五字段 DTO；数据来源边界 `services/business.py`（real 未接真实存储返回 503，不回退 Mock）。
- `APP_MODE=real` 配置强制（缺 OAuth/SMTP/HMAC/HTTPS/Google issuer 直接启动失败）；受控管理员初始化 `scripts/bootstrap_admin.py`（可审计，无公开注册入口）。

### P2/P3 前端（Next.js）

- 页面门禁（服务端，守卫先于业务 Provider）：`app/[[...slug]]/page.tsx` + `lib/auth/server.ts` + `lib/routes.ts#classifyPath`；公开页/个人中心/旧别名/业务区/未知路由分开；业务区仅 active+full 会话挂载 `WorkspaceProvider`；未知路由 404（`app/not-found.tsx`）。
- 登录页重写（`features/auth/LoginPage.tsx`）：移除两个辅助入口与旧链接，Google 按钮只启动真实认证（防重复点击、失败就近提示）；示例卡片标注展示样例。
- 个人中心（`components/account-shell.tsx` + `features/account/AccountView.tsx`）：受限注册模式与已激活模式共用；资料白名单提交、字段级错误、保存并继续/退出（无“稍后完成进首页”）；学校邮箱发码/校验/重发倒计时/换绑流程；状态页区分“学校邮箱已验证”与“学校实名未核验”、教师审核提交/驳回重交。
- 旧链接 `/onboarding/profile|email-verification` → `/account/*`（兼容跳转 + 同门禁）；工作区头像菜单改“个人中心/我的记录/退出登录”（真实注销 + 缓存清理）；演示角色选择器仅 `NEXT_PUBLIC_APP_MODE=mock` 出现；`lib/workspace.tsx` 去除 i18n Provider、缓存按 userId 隔离、`setRole` 生产为空操作。

### P4 语言

- `i18n/config.ts` + `i18n/request.ts`（Cookie > 账户 > Accept-Language > zh-Hans，旧值映射）；`messages/{zh-Hans,zh-Hant,en}.json` 331 键；`components/language-switcher.tsx`（RadioGroup 单选语义、各语言自称、44px 目标）；`app/api/locale` 服务端写 `gp_locale` 白名单 Cookie；已登录同步 `PATCH /me/preferences`，失败提示不伪报成功；切换 `router.refresh()` 保留页面/步骤/未保存输入；HTML lang 跟随 locale；`lib/utils.ts#formatDate` 按当前 locale 格式化（时区 Asia/Macau）。
- 覆盖：登录、个人中心（资料/邮箱/状态）、工作区壳（导航/搜索/头像菜单）、核心入口页（首页/通知/待处理/个人动态）、状态标签/保存状态/空态/错误码词条。

## 剩余限制 / 未联调

1. **真实 Google 联调未做**（缺 GOOGLE_CLIENT_ID/SECRET/REDIRECT_URI 与控制台回调登记）；协议路径已用隔离测试 OIDC 提供方确定性验证，未宣称真实 Google 验收通过。
2. **真实学校邮件未实测**（缺 SMTP 凭据/发信策略）；发送失败路径已验证返回 AUTH_UNAVAILABLE，capture 模式仅限隔离环境。
3. **业务页面词条未全量提取**：本轮覆盖登录/个人中心/工作区壳/核心入口页/共享状态组件（331 键×3 语言）；07–29、31–50、51–56 等业务视图内部文案（`features/project-core|project-support|course|governance` 及 `lib/commands` 提示）仍为中文硬编码，需按 `check:i18n` 同一约定继续提取（用户业务内容原文不翻译）。
4. **业务数据仍为浏览器本地演示适配器**（`lib/api/mock-service.ts`，按 userId 隔离缓存，仅 active 会话挂载）；FastAPI 业务接口授权管线已实现并测试，真实业务表迁移与逐接口适配按[接口交接表](../13-接口交接表.md)推进。
5. 学校邮箱分配细节、学号规则与实名核验接入待学校确认（`STUDENT_ID_EMAIL_RULE=none` 不强制）。
6. 浏览器级完整注册走查（真实 OAuth 跳转后的资料/验证码 UI）依赖 1/2 的真实凭据；本轮 UI 负面用例与 DOM 检查已覆盖，正向 UI 流程以 API 等价流程验证。
