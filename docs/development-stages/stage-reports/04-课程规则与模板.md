# 阶段 04 总结：课程规则与模板

日期：2026-10-06 · 状态：待验收 · 完整记录见[阶段总览](../README.md#阶段实施记录)

## 任务范围

完善教师课程设置/规则模板与课程内助教授权，发布可追溯的课程规则版本，供项目创建与变更处理使用。

## 完成内容

- **命令**（`lib/commands/course.ts`）：`updateCourseSettings`、`saveCourseRuleDraft`（草稿不覆盖已发布版本）、`publishCourseRules`（历史快照 + 兼容字段 + 关联小组复核提醒，重复发布不重复提醒）、`setAssistantPermissions`（白名单不含 staff.manage，撤销保留归属）；共享校验（原因、人数、日期顺序、阶段/材料完整）；ended 课程业务规则只读、授权撤销仍可处理。
- **类型/选择器**：`CourseRulePayload`；`publishedCourseRule`/`draftCourseRule`/`courseRuleHistory`。
- **页面**：47 双操作（保存草稿/发布配置，编辑与发布分别判断 action，发布前显示版本与影响项目数）；46 助教关联 + 三项授权勾选与日志；40 学生总览读取最新已发布版本，草稿不外显。
- **测试**：`npm run check:course-rules`。
